# Skill catalog

No skills are included yet. This directory is intentionally a placeholder.

Future contributions belong in `<name>/SKILL.md`, directly beneath this directory,
with the directory name matching the declared skill name. Do not add example or
template skills here; use the [documentation template](../docs/skill-template.md).

Before adding anything, read [AGENTS.md](../AGENTS.md),
[CONTRIBUTING.md](../CONTRIBUTING.md), and the
[skill standard](../docs/skill-standard.md).

When the first skill is approved, replace this empty-state notice with a catalog
linking each skill and briefly explaining its purpose and limitations.
